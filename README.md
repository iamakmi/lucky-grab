# 🕹️ LUCKY GRAB — QR 럭키드로우 (인형뽑기)

스마트폰을 **집게 컨트롤러**로 쓰는 럭키드로우 웹앱입니다.
PC(또는 TV·모니터)에 큰 화면을 띄워 두고, 참가자는 자기 스마트폰으로 화면의 QR을 스캔해서
집게를 움직이고 `GRAB` 버튼으로 경품을 뽑습니다. 한 번에 한 명씩, 순서대로 돌아가요.

- 설치할 프로그램: **Node.js** 하나 (무료)
- 추가 라이브러리 설치: **없음** (인터넷 없이도 실행됩니다)
- 지원 기기: Windows / Mac / Linux PC + 같은 와이파이에 있는 스마트폰

---

## 1. 준비물 (한 번만 하면 됩니다)

### ① Node.js 설치

1. 브라우저에서 **https://nodejs.org** 에 접속합니다.
2. 초록색 **LTS** 버튼을 눌러 내려받습니다.
3. 내려받은 파일을 실행하고 **Next → Next → Install** 만 계속 누르면 끝입니다.
4. 설치가 끝나면 **컴퓨터를 한 번 재부팅**해 주세요. (안 해도 되지만 확실합니다)

> 이미 Node.js 가 있다면 이 단계는 건너뛰세요.

### ② 압축 풀기

`lucky-grab.zip` 파일의 압축을 풉니다. **바탕화면**이나 **문서** 폴더처럼
찾기 쉬운 곳에 두면 좋습니다.

---

## 2. 실행하기 (매번 이렇게)

### Windows

압축을 푼 폴더 안의 **`start.bat`** 파일을 **더블클릭**합니다.

> 💡 검은 창이 뜨고 글자가 쭉 나오면 정상입니다. 이 창을 **끄지 마세요.**
> 창을 끄면 게임도 꺼집니다.

### Mac / Linux

터미널을 열고 폴더로 이동한 뒤 실행합니다.

```bash
cd ~/Desktop/lucky-grab
chmod +x start.sh     # 처음 한 번만
./start.sh
```

### (선택) 명령어로 실행

```bash
cd lucky-grab
npm install     # 처음 한 번만 (금방 끝납니다)
npm start
```

실행하면 검은 창에 이렇게 주소가 나옵니다.

```
🖥️  메인(디스플레이) 화면 : http://localhost:3000
📱 스마트폰 컨트롤러     : http://192.168.0.12:3000/controller
```

- **PC 화면**은 자동으로 열립니다. 안 열리면 브라우저 주소창에 `http://localhost:3000` 을 입력하세요.
- 큰 TV나 모니터에 연결해 두면 더 좋습니다. 화면 오른쪽 위 **⛶** 버튼을 누르면 전체 화면이 됩니다.

---

## 3. 스마트폰으로 참가하기

1. 스마트폰이 **PC와 같은 와이파이**에 연결되어 있는지 확인합니다.
2. PC 화면 오른쪽의 **QR 코드**를 스마트폰 카메라로 비춥니다.
3. 화면에 뜬 링크를 눌러 컨트롤러 페이지를 엽니다.
4. **방향키(▲▼◀▶)** 를 꾹 누르면 집게가 움직입니다.
5. 원하는 위치에서 **GRAB (뽑기!)** 버튼을 누릅니다.
6. 집게가 내려가 캡슐을 집어 올리고, 당첨 경품이 화면에 크게 표시됩니다.

> 📌 여러 명이 동시에 접속하면 **줄을 서서 순서대로** 뽑습니다.
> 내 차례가 되면 휴대폰이 진동하고 "내 차례!" 로 바뀝니다.

**QR이 안 될 때**: 스마트폰 브라우저 주소창에 PC 화면에 적힌 주소
(`http://192.168.x.x:3000/controller`)를 직접 입력해도 됩니다.

## 4. 경품 바꾸기 — `prizes.json`

메모장(Windows) 또는 텍스트 편집기로 **`prizes.json`** 파일을 열면 경품을 바꿀 수 있습니다.
**저장한 뒤 검은 창에서 서버를 껐다(Ctrl+C) 다시 켜면** 적용됩니다.

```json
{
  "title": "LUCKY GRAB",
  "subtitle": "QR로 조작하는 럭키드로우",
  "grabDurationMs": 6000,
  "prizes": [
    {
      "id": "americano",
      "name": "스타벅스 아메리카노",
      "color": "#34d399",
      "emoji": "☕",
      "weight": 30,
      "quantity": 8
    }
  ]
}
```

| 항목 | 설명 |
| --- | --- |
| `name` | 화면에 표시될 **경품 이름** |
| `color` | 캡슐 색깔 (`#RRGGBB` 형식, 예: `#ff4fa8`) |
| `emoji` | 경품 앞에 붙는 이모지 (없어도 됨) |
| `weight` | **당첨 확률** 비율. 숫자가 클수록 잘 나옵니다. (30 : 25 : 20 …) |
| `quantity` | **준비한 수량**. 다 떨어지면 그 경품은 더 이상 나오지 않습니다. |

- 경품을 **추가**하려면 `{ ... }` 한 덩어리를 복사해서 쉼표로 이어 붙이면 됩니다.
- **꽝**을 넣고 싶다면 `"name": "아쉽지만 꽝"`, `"quantity": 999` 처럼 큰 수량으로 넣으세요.
- `weight` 가 0 이면 뽑히지 않습니다.

### 남은 수량 초기화

뽑은 기록은 `data/prize-state.json` 에 저장되어, 서버를 껐다 켜도 남은 수량이 유지됩니다.
**처음 상태로 되돌리려면** 서버를 끄고(Ctrl+C):

```bash
npm run reset
```

다시 `npm start`(또는 `start.bat`)로 실행하면 `prizes.json` 의 수량으로 새로 시작합니다.
`data` 폴더의 `prize-state.json` 파일을 직접 지워도 똑같습니다.
(`prizes.json` 의 `quantity` 숫자를 바꾸면 자동으로 새 수량으로 다시 시작합니다.)

## 6. 안 될 때 확인해 보세요

| 증상 | 해결 방법 |
| --- | --- |
| `start.bat` 창이 잠깐 떴다 사라짐 | Node.js 가 설치되지 않았을 수 있습니다. 1번 단계를 다시 확인하세요. |
| `'npm'은(는) 인식되지 않습니다` | Node.js 설치 후 **재부팅**이 필요합니다. |
| 스마트폰에서 QR 링크가 안 열림 | ① 같은 와이파이인지 확인 ② **Windows 방화벽** 창이 뜨면 **"액세스 허용"** 클릭 ③ 주소를 직접 입력 |
| 화면에 "컨트롤러 연결 대기 중"만 보임 | 스마트폰이 컨트롤러 페이지까지 열렸는지 확인하세요. (Wi-Fi가 '게스트' 망이면 서로 연결되지 않습니다) |
| 주소가 `localhost` 로만 나옴 | 와이파이가 꺼져 있거나 공유기와 연결이 끊긴 상태입니다. Wi-Fi를 연결하고 다시 실행하세요. |
| 포트가 이미 사용 중이라고 나옴 | 자동으로 다음 포트(3001, 3002…)로 실행됩니다. 콘솔에 표시된 주소를 쓰세요. |
| 두 대 이상 PC로 접속 | 한 대만 메인 화면(`/`)을 열고, 나머지는 컨트롤러(`/controller`)로 접속하세요. |

## 7. 폴더 구성

```
lucky-grab/
├── start.bat          ← Windows 실행 파일 (더블클릭)
├── start.sh           ← Mac/Linux 실행 파일
├── server.js          ← 서버 (HTTP + WebSocket)
├── prizes.json        ← ★ 경품 설정 파일
├── package.json
├── README.md
├── lib/ws.js          ← 외부 패키지 없는 WebSocket 구현
├── data/              ← 남은 수량 자동 저장 (실행하면 생김)
└── public/
    ├── index.html     ← 메인 디스플레이 화면
    ├── controller.html← 스마트폰 컨트롤러 화면
    ├── css/, js/      ← 화면 디자인과 3D 렌더링
    └── vendor/qrcode.js (MIT, QR 코드 생성)
```

## 8. 게임 규칙

- 참가자는 스마트폰으로 접속한 **순서대로** 한 명씩 뽑습니다.
- 한 사람이 뽑고 나면 자동으로 다음 사람에게 차례가 넘어갑니다.
- 남은 경품 수량은 화면 아래에 실시간으로 표시됩니다.
- 모든 경품이 떨어지면 "경품 소진" 안내가 나옵니다. (`prizes.json` 에서 수량을 늘려 주세요)
